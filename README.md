## 📖 1. فكرة المشروع (Project Concept)

يعاني مهندسو ومراقبو الشبكات في مراكز العمليات (NOC) والمتدربون الجدد من تحديين رئيسيين:
1. **استهلاك الوقت في استكشاف الأعطال:** صعوبة وتشتت تشخيص أعطال التكوين المعقدة في بيئات Cisco IOS وأنظمة Linux للاتصالات.
2. **مخاطر الخصوصية وتسريب الأسرار:** لجوء المهندسين إلى أدوات الذكاء الاصطناعي العامة لحل المشكلات يؤدي لتسريب كلمات المرور المشفرة (Secrets)، وعناوين الـ IP الحساسة، وسلاسل الـ SNMP، والمفاتيح الخاصة خارج نطاق المنشأة.

**NetTroubleshooter AI** يقدم بيئة تشخيص وتدريب ذكية تجمع بين سرعة التحليل الفني، وتوليد أوامر الإصلاح المباشرة، وحماية خصوصية بيانات البنية التحتية عبر **فلترة وتطهير البيانات الحساسة من جهة العميل (Client-Side Data Masking)** قبل أي معالجة.

## 🚀 2. المميزات الأساسية للنموذج الأولي (Key Features)

- **🎨 واجهة غرف العمليات الاحترافية (NOC/SOC Dark Theme):**
  - دعم كامل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl"`).
  - تصميم عصري وسريع التجاوب مع خطوط تقنية مخصصة (Cairo و JetBrains Mono).
- **🔒 فلتر الخصوصية وتطهير البيانات (Client-Side Data Masking):**
  - حجب فوري لكلمات المرور (`enable secret`, `password`, `pre-shared-key`).
  - إخفاء عناوين IPv4 الحساسة واستبدالها بمعرفات رمزية آمنة (مثل `[MASKED_IP_1]`).
  - حجب سلاسل SNMP Communities ومفاتيح المصادقة.
  - جدول تحويل محلي (Local Mapping Table) يضمن بقاء البيانات داخل جهاز المستخدم دون إرسالها لأي خادم وسيط.
- **⚡ سيناريوهات تجربة سريعة بضغطة زر (One-Click Presets):**
  1. **عطل VLAN Trunking و Native VLAN Mismatch (Cisco)**: تشخيص تسريب الـ VLANs وتعارض البروتوكولات على منافذ الربط.
  2. **خطأ توجيه OSPF / MTU Mismatch (Cisco)**: حل مشكلة بقاء جيران OSPF عالقين في حالة EXSTART/EXCHANGE.
  3. **انقطاع شبكة خادم Linux (Netplan & DNS Conflict)**: حل تضارب البوابات الافتراضية وحظر منافذ الـ DNS في iptables.
  4. **فحص الثغرات والتدقيق الأمني**: كشف المنافذ المفتوحة وبروتوكولات الإدارة غير المشفرة.
- **📊 بطاقات التشخيص الأربع المتقدمة:**
  1. **سبب العطل الفني بدقة (Root Cause Analysis):** بيان السبب الجذري، وتحديد الطبقة المتأثرة من نموذج OSI (Layer 2 / Layer 3)، وتقدير الأثر التشغيلي.
  2. **خطوات الحل المنهجية (Methodical Steps):** خطة عمل تفاعلية مرقمة تناسب مهندسي ومتدربي الشبكات.
  3. **أوامر الإصلاح الجاهزة للنسخ (Copy-ready CLI Remediation):** كود CLI تنفيذي كامل مع زر نسخ مباشر وأوامر تحقق (Verification) وتراجع (Rollback).
  4. **تقرير التدقيق الأمني (Security Audit & Compliance):** قياس درجة أمان الإعدادات، والتنبيه بالثغرات مثل استخدام Telnet أو كلمات مرور غير مشفرة أو إتاحة SNMP للعامة وفق معايير CIS Benchmarks.
- **💻 تشغيل محلي بالكامل (100% Client-Side):**
  - لا يتطلب مفاتيح API خارجية، ولا قواعد بيانات، ولا اشتراكات مدفوعة، ويعمل دون اتصال بالإنترنت (Offline-Ready).

## 🛠️ 3. كيفية التشغيل (How to Run)

النموذج مصمم ليعمل بصفر متطلبات تثبيت (Zero-Dependency):

### الطريقة الأولى: التشغيل المباشر
فقط انقر نقراً مزدوجاً (Double Click) على ملف:
```
index.html
```
سيفتح مباشرة في متصفحك المفضل (Chrome, Edge, Firefox, Safari).

### الطريقة الثانية: عبر خادم محلي سريع (اختياري)
إذا كنت تفضل تشغيله عبر سيرفر محلي (مثل Python أو VS Code Live Server):

```bash
# باستخدام بايثون 3
python -m http.server 8080
```
ثم افتح المتصفح على الرابط: `http://localhost:8080`
